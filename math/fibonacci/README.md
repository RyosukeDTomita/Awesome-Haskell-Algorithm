# フィボナッチ数列まとめ

- [再帰](./fibonacciRecursive.hs): 単純に再帰で定義したもの。複数回同じ値を計算するため、計算効率が悪い。
- [一度計算した値を保存する](./fibonacciCache.hs): メモ化
- [遅延評価を活かした実装](./fibonacciLazy.hs): Haskellは無限リストを定義できる。これを利用して、`zipWith`を使い、フィボナッチ数列と1つ添字をずらしたフィボナッチ数列の各項を足し合わせることでフィボナッチ数列を再現している。Haskellの遅延評価はcall-by-needなので、同じ式が複数回評価されず、メモ化と同様の効果が得られている。
- [ストリームを使うバージョン](./fibonacciStream.hs): `iterate`で`a_n`と`a_n+1`を状態として持ち、これらを足し合わせることで、フィボナッチ数列を作る。状態を渡していくため、遅延評価やメモ化がなくても、計算効率が悪くならない。

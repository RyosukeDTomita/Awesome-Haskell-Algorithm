# サーチアルゴリズムまとめ

## 線形探索(Liner Search)

- [linear_search/linearSearch.hs](./linear_search/linearSearch.hs)
- 先頭から対象となる値を探す。
- 計算量は O(n)。

### 線形探索 with 番兵法(Sentinel loop)あり

- [linear_search/linearSearchSentinelLoop.hs](./linear_search/linearSearchSentinelLoop.hs)
- Haskellで実装する場合、基本的に旨味がない。
- 前提として線形探索においてループの終了条件は，以下の 2 つがある。
  - 探索する値が見つかったか
  - 探索する値が見つからなかった場合に配列の末尾に到達したか
- 探索する配列に番兵として探索する値を末尾に追加することで，必ず探索する値が見つかるようになるため，ループの終了条件を探索する値が見つかったかの 1 つにすることができる。

## 二分探索(Binary search)

- [binary_search](./binary_search)
- データがソート済みであることが必要。
- データを左右半分にわけ、ターゲットとなる値が左右のどちらにあるかを判定することで探索範囲を絞っていく。
- 計算効率は、1ステップごとに探索対象が半分になっていく。これは 2進数においては、1桁減ることを表しているので計算量は O(log2 n)と表せる。

---

## BST(Binary Search Tree)

- [bst.hs](./bst.hs)
- 二分木探索とも。
- 各ノードに値が格納されており、左の子ノードは親ノードより小さい値、右の子ノードは親ノードより大きい値を持つという構造を維持する二分木。
- ノードの削除時には、そのノードの右部分木の最小値を持つノードを削除するノードの位置に移動させることで、BSTの構造を維持する。
  - 右部分技の最小値は、左部分木のどの値よりも大きいが、右部分木のどの値よりも小さいため、BSTの構造が維持される。
  - (右部分木の最小値は、子ノードがないので移動させやすい。)

---

## bit 全探索(bit search)

- [bitSearch.hs](./bitSearch.hs)
- n個の要素が2種類の状態を持つとき、その全パターンを前列挙して探索する方法
  - n個の要素をもつ集合の部分集合は2^n通りあり、これをbit列に対応させる
- 整数のi桁目のbitが1ならi番目の要素を採用すると考えることで、すべての部分集合を漏れなく列挙できる。
- 計算量は部分集合の列挙にO(2^n)、各部分集合の評価に最低O(n)かかるためO(2^n * n)と大きくなる。nが小さい(目安として20程度以下)場合に有効。

## 深さ優先探索(Depth First Search)

- [dfs/](./dfs/)
- `(頂点, 隣接頂点のリスト)`のグラフ構造を扱う。
- 開始位置(頂点)から、到達できる頂点を深さ優先で訪問する。
  - 頂点Aからみた隣接頂点のリストB,Cがある場合、A -> B -> Bの隣接頂点の最初の値... のような順で訪問する(LIFO)

---

## 幅優先探索(Breadth First Search)

- [BreadthFirstSearch.hs](./BreadthFirstSearch.hs)
- 深さ優先探索同様に`(頂点, 隣接頂点のリスト)`のグラフ構造を扱う。
- 開始位置(頂点)から、到達できる頂点を幅優先で探索する
  - 頂点Aからみた隣接頂点のリストB,Cがある場合、隣接頂点リストを消化することを優先する(FIFO)

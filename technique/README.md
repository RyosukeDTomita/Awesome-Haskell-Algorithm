# アルゴリズム技法(technique)

特定のデータ構造や問題領域に属さず、前計算やデータの持ち方を工夫して計算量を落とす汎用的な技法をまとめる。

---

## 累積和

- [cumulativeSum.hs](./cumulativeSum.hs)
- 先頭からの総和を前計算しておき、区間和を引き算1回で求める。
  - 前計算O(n)
  - 区間和クエリO(1)
- 累積和をs、元の列をxsとすると`s[i] = xs[0] + ... + xs[i-1]`であり、半開区間`[l, r)`の和は`s[r] - s[l]`
- 累積和sの長さは元の列より1つ長いn+1になる(先頭に単位元0が入る)
  - 単位元0を入れずに`scanl1`などで作るとlistが0-indexなので使いにくい
